# 771 Screenshot Tool（独立版）

从 **柒柒壹工具箱** 里单独拆出来的截图工具：**一个入口 exe，双击即用**，不依赖工具箱、也不用安装任何东西。
常驻后台，随时用快捷键截图。
注:该软件为100%AI

## 功能（全部离线可用）
- 浅色 / 深色 / 跟随系统主题；切换时从状态栏「主题」控件中心向外扩张成水滴涟漪（v2.0.26），不再出现整窗弥散渐变
- 区域截图 / 取色 / 标尺的蒙层期间暂停窗口边缘缩放热区（v2.0.27）：鼠标移到屏幕边缘保持十字，框选不会被打断；退出后窗口边缘缩放恢复
- 滚动截图遮罩（v2.0.28）：框选阶段选中区域提亮并带亮蓝边框，未选区为灰色；真正滚动时保留灰色遮罩，选区内透明显示实时页面，控制条浮在遮罩上；结果图不含遮罩/边框。
- 蒙层保持置顶（v2.0.29）：浏览器等窗口在前台时，鼠标移到窗口边缘保持十字，不再变成缩放指针或打断框选；关闭蒙层还原窗口后不再偶发闪退。
- 首帧焦点修复（v2.0.30）：冷启动 / 最小化后第一次截图，Esc 和 Enter 直接可用；恢复前台激活脉冲（蒙层仍保持置顶），并加 SwitchToThisWindow 兜底与首帧焦点连续重试。
- 区域截图（拖框 → 标注 → Enter 存并进剪贴板）/ 全屏 / 窗口截图 / 滚动截图
  （滚动截图：拖框后按 Enter 开始滚动，自动拼接整页；滚动中窗口缩成控制条，点「完成」或按 Esc 随时停下并保存）
- 标注器九工具：矩形 / 椭圆 / 箭头 / 铅笔 / 文字（拖框定位，定位框透明、成图无边框）/
  马赛克 / 模糊 / 高亮 / 序号（五色 + 线宽 + 撤销/重做）
- 取色器（点击复制 HEX）/ 屏幕标尺 / 贴图（无边框置顶、可拖动缩放）
- 图片取字（Windows 系统 OCR，无需安装任何东西）
- 预览区：放大查看 / 标注… / 取字 / 复制路径 / 在文件夹中显示

## 全局热键（默认键位）
区域 `Ctrl+Alt+A` · 全屏 `Ctrl+Alt+S` · 窗口 `Ctrl+Alt+W` · 滚动 `Ctrl+Alt+G` · 取色 `Ctrl+Shift+C` ·
标尺 `Ctrl+Shift+M` · 标注最近一张 `Ctrl+Alt+N` · 贴图 `Ctrl+Shift+P`

按键都可以在界面「快捷键」表里点按修改（改完自动保存，重启后仍生效）。

窗口收在任务栏（最小化）时也能用：区域/窗口/取色/标尺/标注这些需要界面的流程会自动把窗口
弹出来用、用完自动收回去；全屏/贴图本来就不看窗口。
