# 771 Screenshot Tool（独立版）

从 **柒柒壹工具箱** 里单独拆出来的截图工具：**一个入口 exe，双击即用**，不依赖工具箱、也不用安装任何东西。
常驻后台，随时用快捷键截图。
注:该软件为100%AI

当前版本：**v2.0.9**（2026-10-16）· Windows 10 / 11（64 位）

> **v2.0 起软件换成 Flutter 新版外壳**——同一个软件、同一个入口 exe 名称、同样的保存目录与
> 剪贴板习惯，原有快捷键与开机自启不受影响。旧版（v1.32，tkinter 外壳）仍可在历史 Release 下载。

**从 v1.19 起带联网自动更新**：启动后会在后台查一次新版本（失败静默），发现新版会弹窗询问，
下载后自动校验（Ed25519 签名 + SHA-256）再替换并重启。也可以手动到 Releases 下载。

## 功能（全部离线可用）
- 区域截图（拖框 → 标注 → Enter 存并进剪贴板）/ 全屏 / 窗口截图 / 滚动长图
- 标注器九工具：矩形 / 椭圆 / 箭头 / 铅笔 / 文字（拖框定位，定位框透明、成图无边框）/
  马赛克 / 模糊 / 高亮 / 序号（五色 + 线宽 + 撤销/重做）
- 取色器（点击复制 HEX）/ 屏幕标尺 / 录制 GIF（可提前停止）/ 贴图（无边框置顶、可拖动缩放）
- 图片取字（Windows 系统 OCR，无需安装任何东西）
- 预览区：放大查看 / 标注… / 取字 / 复制路径 / 在文件夹中显示

## 全局热键（默认键位）
区域 `Ctrl+Alt+A` · 全屏 `Ctrl+Alt+S` · 窗口 `Ctrl+Alt+W` · 取色 `Ctrl+Shift+C` ·
标尺 `Ctrl+Shift+M` · 标注最近一张 `Ctrl+Alt+N` · 贴图 `Ctrl+Shift+P` · 录制 `Ctrl+Shift+R`

窗口收在任务栏（最小化）时也能用：区域/窗口/取色/标尺/标注这些需要界面的流程会自动把窗口
弹出来用、用完自动收回去；全屏/录制/贴图本来就不看窗口。
